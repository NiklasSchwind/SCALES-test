# fastMIP Sample Output

This is sample output. It was generated using
temperature data from the PROVIDE project.

The structure we envision for the output is:
output_folder/
├── mesmer/
    ├── tas/       # cross-scenario files (e.g., scenario uncertainties stored here)
        ├── L/     # scenario-specific information stored here
        ├── H/
        ├── ...
    ├── pr/
    ├── .../
├── meteor/
├── prime/
└── .../

As sample output, we provide mesmer temperature data
for the ModAct scenario.
